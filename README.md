Java Lab Experiments

Repository Structure
Each experiment is stored in its own folder. Open the relevant folder to find its source code, dependencies, configuration files, and any experiment-specific README.
General Setup
Requirements vary by project. Depending on the experiment, you may need:
- JDK
- Visual Studio Code or another Java IDE
- MySQL and MySQL Connector/J for JDBC projects
- Apache Maven for Maven-based projects
- Apache Tomcat for Servlet/JSP web applications
Running the Projects
Each project has its own setup steps:
- Plain Java / Swing: Open the project in a Java IDE and run the class containing main().
- JDBC: Start MySQL, create the required database/table, configure database credentials, and include the JDBC driver.
- Java Socket: Start the server program first, then run the client.
- RMI: Start the RMI server before running the client.
- Servlet/JSP: Build the WAR with Maven if applicable, deploy it to a compatible Tomcat server, start Tomcat, and open the application's URL in a browser.
Refer to the individual project README files for exact commands and configuration.
